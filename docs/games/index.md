# The collection

Every exhibit is a separate project with its own repository, site and releases. They share conventions, tooling
and the [gasm](/gasm) runtime, so what one learns the next one inherits. They are ordered by the year the original
came out.

<ExhibitGrid />

## The gasm wing

Two more classics run on the same runtime, as ports of existing open engines rather than ENCORE
reimplementations: DOOM, from id Software's released source, and ScummVM, the long-running reimplementation of
the engines behind dozens of adventure games. They live in the [gasm](/gasm) repository and its demo page, and
proved much of the runtime before the first ENCORE port did.

<GasmWing />

::: tip You bring the game
None of these projects contain the original game's code, art, sound or data. Each one reads your own disc or
installed copy, and most check that it is the exact version they were built against. See
[Bring your own copy](/about/your-copy).
:::

## Status, briefly

**Playable** means the game runs from its menus to its end in the reimplementation; it does not mean every
pixel has been compared with the original yet — each project's own status page says exactly what has.
**In progress** means large parts run, with known stand-ins. **Groundwork** means the research, file layer and
port plan exist, but the game itself does not run yet.
